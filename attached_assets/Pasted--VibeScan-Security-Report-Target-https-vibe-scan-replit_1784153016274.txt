#### 🟠 HIGH — Missing Content-Security-Policy (CSP)
**Category:** Injection Defense

**Description:** No Content-Security-Policy header was found. CSP is the primary browser-enforced defense against Cross-Site Scripting (XSS) attacks. Without it, injected scripts can run with full page privileges and steal session cookies or credentials.

**Evidence:**
```
GET https://vibe-scan.replit.app/
Content-Security-Policy: (header absent from response)
```
**How to Fix:** Implement a strict CSP. A starting point: Content-Security-Policy: default-src 'self'; script-src 'self'; object-src 'none'; base-uri 'self'. Tighten over time using CSP violation reports.

**References:** CWE-79 | CVSS 7.2 | WSTG-CONF-12

#### 🟡 MEDIUM — Missing Clickjacking Protection (X-Frame-Options)
**Category:** UI Security

**Description:** The application does not set X-Frame-Options or CSP frame-ancestors. Attackers can embed your pages in invisible iframes on malicious sites and trick users into clicking UI elements (clickjacking).

**Evidence:**
```

#### ⚪ INFO — Missing Cross-Origin-Opener-Policy (COOP)
**Category:** Browser Feature Control

**Description:** The Cross-Origin-Opener-Policy header is not set. COOP isolates your browsing context from cross-origin popups, preventing other pages from accessing your window object. It is required to safely enable SharedArrayBuffer and high-resolution timers. Most public web apps do not need these APIs, so absence is typically informational — but enabling COOP is a free defence-in-depth measure.

**Evidence:**
```
GET https://vibe-scan.replit.app/
Cross-Origin-Opener-Policy: (header absent from response)
```
**How to Fix:** Add: Cross-Origin-Opener-Policy: same-origin (most secure) or same-origin-allow-popups if you need cross-origin popup interaction. Only required if you use SharedArrayBuffer or high-resolution timers.

**References:** CWE-346 | WSTG-CONF-07

It is required alongside COOP to achieve cross-origin isolation. Absence is informational for most sites — only needed if your app uses SharedArrayBuffer or high-resolution performance timers.

**Evidence:**

```
**How to Fix:** Add: Cross-Origin-Embedder-Policy: require-corp. Note: this requires all subresources to serve a CORP or CORS header. Use credentialless if require-corp causes third-party resource breakage.

**References:** CWE-346 | WSTG-CONF-07

#### ⚪ INFO — Missing Cross-Origin-Resource-Policy (CORP)

For most public resources this is informational — but adding CORP: same-origin or same-site is a low-effort hardening step.

**Evidence:**
```
GET https://vibe-scan.replit.app/
Cross-Origin-Resource-Policy: (header absent from response)
```
**How to Fix:** Add: Cross-Origin-Resource-Policy: same-origin (for same-site-only resources) or same-site. Use cross-origin only for truly public resources.

**References:** CWE-346 | WSTG-CONF-07
